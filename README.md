# Engineering Student Portal — Final Updated

This version preserves the portal structure and adds the requested placement, learning and practice features.

## Key updates
- Placements & Internships is one combined section; internships are inside Job Alerts.
- Placement Hub with company directory, tier, official company website and official careers links.
- Company Preparation and Previous Placement Questions by company/category.
- Placement Experiences with student-journey fields and Admin add/edit/delete.
- E-Library with existing resources plus Apna College video resources.
- Technical Skills & Resources with skill-specific notes/PDFs, links and Apna College resources where relevant; Admin PDF/link/video management.
- Separate Coding Practice and separate Internship Opportunities menus are removed.
- Interview Preparation supports text and browser voice input, with I Don't Know → reference answer + explanation.
- Expanded Interview Question Bank.
- Daily Practice starts with subject/topic selection and MCQs, Submit, I Don't Know, explanations and results.
- Free Courses & Certifications retains course-style learning resources and adds free resources.
- Project Ideas use external tutorials/open-source references/datasets/deployment resources; personal project links are excluded.
- Admin dashboard supports CRUD for major content collections.
